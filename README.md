# 競馬データ分析パイプライン（ポートフォリオ公開版）

競馬データを題材に、Pythonで  
**Webデータ取得 → HTML解析 → DataFrame化 → データ整形 → 品質チェック → 特徴量生成**  
までを行った個人開発の一部を、転職活動向けに整理したものです。

> 実際の個人開発では、独自特徴量の生成や機械学習による予測まで実装しています。
> ただし、予測精度に関わる独自ロジック・具体的な判定条件・学習モデル等は公開していません。

## 取り組んだこと

- Seleniumを使ったWebデータ取得
- 取得失敗時のリトライ、待機時間、取得済みデータのスキップ処理
- BeautifulSoupを使ったHTML解析
- pandasを使ったDataFrame化、型変換、重複削除
- 複数データの整形・結合
- 欠損や重複などのデータチェック
- 過去データを使った基本的な特徴量生成
- 実際の開発ではLightGBMを使った予測モデルも作成（非公開）

## 使用技術

- Python
- pandas
- Selenium
- BeautifulSoup4
- webdriver-manager

## 処理の流れ

```text
Webデータ取得
   ↓
HTML保存
   ↓
HTML解析
   ↓
DataFrame / CSV化
   ↓
データ整形・品質確認
   ↓
特徴量生成（一部のみ公開）
   ↓
機械学習・予測（非公開）
```

### `race_scraper_sample.py`
Seleniumを使ってWebページを取得する処理のサンプルです。  
取得失敗時のリトライやランダム待機、取得済みファイルのスキップなどを入れています。

### `race_parser_sample.py`
保存したHTMLをBeautifulSoupで解析し、必要なデータをDataFrameに変換する処理です。

### `payout_processor.py`
文字列で保存された払戻情報を整理し、券種ごとの数値データに変換します。

### `data_validation.py`
重複データや必須列、日付の欠損などを確認するための処理です。

### `feature_engineering_sample.py`
出走頭数、馬番の位置、前走からの日数など、一般的な特徴量生成のみ掲載しています。  
実際の予測に使用している独自特徴量は含めていません。

## この開発を通じて学んだこと

最初から整理されたデータを使うのではなく、Web上からデータを取得し、
分析や機械学習で使える形に整えるところから作成しました。

その中で、欠損データ、重複、文字コード、HTML構造の違い、
取得失敗への対応など、データを扱う上で必要になる処理を経験しました。

また、予測モデルを作るだけでなく、
入力データの品質確認や、処理を繰り返し実行できるようにすることも重要だと学びました。
